01 About the game

One bird.
Endless sky.

Happy Bird is an indie arcade game inspired by Flappy Bird — with its own identity, its own code and a fully open-source repository. Tap to flap, slip through the pipes and keep the cheerful little bird in the air.

It is built to be instantly playable: a single universal Windows build that runs on Windows 7 and every version since, no installer maze, no account needed.

  • One-button, pick-up-and-play flying
  • Day and night worlds, classic pipe courses
  • Arcade sound effects for every flap, point and crash
